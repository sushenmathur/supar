Door status on the Home view

Three ways to show how many doors are open. Each counts Front, Crimsafe, Side, Laundry and Patio door contacts plus the garage door. Use the buttons to see each option with different doors open.

All options: the status updates live from the door sensors, and tapping it opens the Cameras view, which already lists every door. Garage uses the garage door itself, so "opening" and "closing" count as open. If you would rather keep the garage out of the count (it already has its own tile on the Security card), say so and I will leave it out.
